# AI Classification Project

## 📌 Description
This project is a basic supervised learning model that classifies iris flowers using machine learning.

## 🧠 What this project does
- Loads dataset
- Splits data into training and testing sets
- Trains a Logistic Regression model
- Predicts results
- Shows accuracy

## ⚙️ Technologies Used
- Python
- Pandas
- Scikit-learn
